## Mục tiêu

- Hệ thống hóa những khái niệm quan trọng của Go.
- Xây dựng tài liệu tra cứu ngắn gọn, dễ cập nhật.
- Kết hợp lý thuyết với ví dụ có thể chạy và bài tập thực hành.
- Theo dõi tiến độ học theo từng chương.
